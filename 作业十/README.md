# 作业十：正弦位置编码 (Sinusoidal PE) 与 RoPE 旋转位置编码对比实验

## 一、实验简介
本实验基于 PyTorch 实现传统加法式正弦位置编码与 RoPE 旋转位置编码，完成底层数学实现、流程对比、可视化绘图与数值验证，直观对比两种位置编码的实现逻辑、特征表现与核心特性，验证 RoPE 天然适配相对位置的优势。

## 四、代码功能模块说明（对应 5 项代码任务）
任务 1：Sinusoidal PE 正弦位置编码实现
实现标准 Transformer 加法式位置编码，通过正弦、余弦函数生成固定位置向量，可与词嵌入 Embedding 逐元素相加融合。
输出可视化：pe_heatmap.png，直观展示不同位置、不同维度 PE 数值分布规律。

任务 2：二维向量旋转基础单元
实现 RoPE 底层数学逻辑：二维向量正交旋转变换，仅改变向量夹角、不改变向量模长，是高维 RoPE 的基础组件。

任务 3：高维 RoPE 批量旋转实现
将高维向量两两分组，每组独立执行二维旋转；根据 token 位置分配对应旋转角度，批量处理 batch、多序列长度张量。
输出可视化：rope_feature.png，对比同一向量在 pos=0 与 pos=10 经过 RoPE 变换后的特征差异。

任务 4：两种位置信息注入流程对比
E+PE 加法模式：词嵌入与位置编码输入阶段直接相加，语义与位置全程混合；
RoPE 旋转模式：原始词嵌入不修改，仅对 Q、K 向量执行旋转，Value 向量无变换；
输出可视化：add_vs_rope.png，流程图直观区分两种实现逻辑。

任务 5：数值实验验证 RoPE 相对位置特性
固定 Q、K 向量，设置多组「绝对位置不同、相对偏移相同」的样本，计算旋转后点积相似度；
实验证明：RoPE 的注意力分数仅由 token 相对距离决定，与绝对位置无关；
输出可视化：rope_relative.png，绘制点积随相对偏移变化曲线，终端打印数值结果佐证结论。

## 六、实验核心结论
传统 E + 正弦 PE 采用加法融合，语义信息与位置信息相互耦合污染，点积依赖绝对位置，长文本外推能力差；

RoPE 采用正交旋转变换，仅修改 Q、K 向量夹角，保留原始语义向量幅值；注意力分数天然只和 token 相对距离相关，更贴合自然语言上下文依赖特性；

RoPE 无需在输入阶段混合位置信息，原始 Embedding、Value 向量保持纯净，模型泛化能力、超长序列适配性优于传统加法 PE。
